# «نبّه» — محاكاة توعوية لرموز QR

**الرابط العام:** https://bushlaibi105-ux.github.io/nabbih/

صفحة ثابتة (HTML/CSS/JS بدون بناء). تبدأ المحاكاة تلقائيًا عند فتح الرابط، بدون أي زر، ولا تطلب أذونات ولا ترسل بيانات.

| الوقت | المشهد |
|---|---|
| 0–1 ث | صفحة «شارك معنا» — يتجمد شريط التحميل، يرتعش عنصر، إطار أسود خاطف |
| 1–3 ث | عناصر الصفحة تختفي، أدوات المطوّر تفتح وحدها بسجل نشاط مريب، الصفحة تخفت تدريجيًا |
| 3–6 ث | تسارع السجلات، المفتّش يلتقط العنوان ويُعاد كتابته، لوحة Network، تمزق وتجمد خاطف |
| 6–6.6 ث | قطع مفاجئ: شاشة سوداء وصمت |
| بعدها | «لا تخاف، جهازك آمن…» ثم الرسالة الأخيرة وشعار «نبّه» |

الأصوات اختيارية: تعمل فقط إذا سمح المتصفح (أو لمس الزائر الشاشة)، والتجربة لا تعتمد عليها.
نصا العنوان المخترَق قابلان للتعديل في `config.json` (`hijackLine1`, `hijackLine2`).

## التعديل
- فرع `main` هو المصدر. أي تعديل عليه يُنشر تلقائيًا (Actions ← «Publish & verify») ثم يُفحص الرابط العام.
- **الشعار:** ارفع صورتك باسم `assets/logo.png` على فرع `main` وتظهر بدل الشعار النصي. لمسار آخر عدّل `"logo"` في `config.json`.
- **النصوص:** كلها في `config.json`.
- `?calm=1` في الرابط يعرض نسخة بدون وميض (وتُفعّل تلقائيًا مع «تقليل الحركة»).

# «نبّه» — محاكاة توعوية لرموز QR

**الرابط العام:** https://bushlaibi105-ux.github.io/nabbih/

صفحة ثابتة (HTML/CSS/JS بدون بناء). تبدأ المحاكاة تلقائيًا عند فتح الرابط، بدون أي زر، ولا تطلب أذونات ولا ترسل بيانات.

| الوقت | المشهد |
|---|---|
| 0–2.6 ث | صفحة «شارك معنا في مبادرة نبّه» كما هي |
| 2.6–3.0 ث | هدوء مريب: يتجمد شريط التحميل، ارتعاشة، إطار أسود خاطف |
| 3.0–5.0 ث | عناصر الصفحة تختفي، أدوات المطوّر تفتح وحدها، الصفحة تخفت إلى الأسود |
| 5.0–12.5 ث | المشهد الأسود على ثلاث مراحل: إعادة كتابة الصفحة ← اتصال بالخارج (Network) ← «Paused in debugger» ثم السيطرة |
| 12.5–13.1 ث | قطع مفاجئ: أسود وسكون |
| 13.1 ث → | «لا تخاف، جهازك آمن» + «هذه مجرد محاكاة توعوية» — تبقى ثابتة، وزر إعادة هادئ يظهر بعد 4.5 ث |

الأصوات اختيارية: تعمل فقط إذا سمح المتصفح (أو لمس الزائر الشاشة)، والتجربة لا تعتمد عليها.
نصوص العنوان المخترَق قابلة للتعديل في `config.json` (`hijackLine1`, `hijackLine2`, `hijackLine3`).

**ملء الشاشة:** الصفحة تملأ كامل المساحة المتاحة (`viewport-fit=cover` و`100dvh`). على Android يتحول المتصفح لملء الشاشة الحقيقي عند أول لمسة من الزائر (المتصفحات لا تسمح بذلك بدون لمسة). Safari على iPhone لا يدعم ملء الشاشة لصفحات الويب، فيبقى شريطه ظاهرًا.

## التعديل
- فرع `main` هو المصدر. أي تعديل عليه يُنشر تلقائيًا (Actions ← «Publish & verify») ثم يُفحص الرابط العام.
- **النصوص:** كلها في `config.json`.
- `?calm=1` في الرابط يعرض نسخة بدون وميض (وتُفعّل تلقائيًا مع «تقليل الحركة»).

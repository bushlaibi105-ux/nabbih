# «نبّه» — محاكاة توعوية لرموز QR

**الرابط العام:** https://bushlaibi105-ux.github.io/nabbih/

صفحة ثابتة (HTML/CSS/JS بدون بناء). تبدأ المحاكاة تلقائيًا عند فتح الرابط، بدون أي زر، ولا تطلب أذونات ولا ترسل بيانات.

| الوقت | المشهد |
|---|---|
| 0–2 ث | صفحة «شارك معنا في مبادرة نبّه» كما هي |
| 2.0–3.6 ث | Browser Takeover: الصفحة تتعطل وتتزحزح، نوافذ أخطاء داخل الصفحة تظهر ثم تتكدس بسرعة، والصفحة تخفت |
| 3.6–5.0 ث | قطع إلى الأسود: سجل أحداث مختصر جدًا يتسارع |
| 5.0–5.5 ث | تعليق مفاجئ (Freeze) — بصريًا فقط |
| 5.5–7.5 ث | سواد كامل بلا نص ولا حركة |
| 7.5 ث → | «لا تخاف، جهازك آمن» + «هذه مجرد محاكاة توعوية» + «نادي الذكاء الاصطناعي» — ثابتة |

النوافذ طبقات HTML داخل الصفحة نفسها (ليست نوافذ متصفح ولا تنبيهات نظام)، ولا تحتوي أزرارًا.

الأصوات اختيارية: تعمل فقط إذا سمح المتصفح (أو لمس الزائر الشاشة)، والتجربة لا تعتمد عليها.
نص تعطل الصفحة قابل للتعديل في `config.json` (`stallText`).

**ملء الشاشة:** الصفحة تملأ كامل المساحة المتاحة (`viewport-fit=cover` و`100dvh`). على Android يتحول المتصفح لملء الشاشة الحقيقي عند أول لمسة من الزائر (المتصفحات لا تسمح بذلك بدون لمسة). Safari على iPhone لا يدعم ملء الشاشة لصفحات الويب، فيبقى شريطه ظاهرًا. عند إضافة الموقع للشاشة الرئيسية يفتح كتطبيق بدون أشرطة المتصفح (`manifest.webmanifest`)، والرابط العادي يبقى يعمل كما هو.

## التعديل
- فرع `main` هو المصدر. أي تعديل عليه يُنشر تلقائيًا (Actions ← «Publish & verify») ثم يُفحص الرابط العام.
- **النصوص:** كلها في `config.json`.
- `?calm=1` في الرابط يعرض نسخة بدون وميض (وتُفعّل تلقائيًا مع «تقليل الحركة»).

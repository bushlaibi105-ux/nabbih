# «نبّه» — محاكاة توعوية لرموز QR

صفحة ويب ثابتة (HTML/CSS/JS بدون أي بناء أو مكتبات). تبدأ تلقائيًا عند فتح الرابط:

| الوقت | المشهد |
|---|---|
| 0–1 ث | صفحة بسيطة: «شارك معنا في مبادرة نبّه» |
| 1–3 ث | Glitch + تحذيرات حمراء (SECURITY WARNING …) |
| 3–6 ث | واجهة فحص سينمائية: رادار، نسبة، Terminal |
| 6–9 ث | «لا تخاف، جهازك آمن…» ثم «تخيل لو كان الرابط خبيثًا فعلًا؟» |
| 9–12 ث | «مو كل QR Code آمن · تأكد قبل ما تمسح · خلك نبّه» + شعار المعرض |

- لا يطلب أي إذن، ولا يرسل أي بيانات، ولا يمنع إغلاق الصفحة.
- زر «تخطي المؤثرات» يظهر أثناء المحاكاة، وتُحترم إعدادات «تقليل الحركة» تلقائيًا (أو أضف `?calm=1` للرابط).
- اسم الجهاز الظاهر في الـTerminal يُقرأ محليًا من المتصفح للعرض فقط ولا يُرسل لأي مكان.

## تغيير الشعار بدون إعادة بناء
ارفع صورة الشعار باسم `assets/logo.png` (يفضّل PNG شفاف بعرض ~800px). الموقع يعرضها تلقائيًا بدل الشعار النصي.
لاسم/مسار مختلف عدّل `"logo"` في `config.json`. لعرض الشعار مع الكلمة النصية اجعل `"showWordmarkWithLogo": true`.
كل النصوص قابلة للتعديل من `config.json` أيضًا. بعد التعديل ارفع التغيير والموقع يتحدث خلال دقيقة.

## الملفات
- `index.html`, `style.css`, `app.js` — التجربة
- `config.json` — النصوص ومسار الشعار
- `assets/fonts` — خط «السعودي» (وزارة الثقافة)
- `qr/nabbih-qr.png` (2460px للطباعة) و `qr/nabbih-qr.svg` (متجه)

## التشغيل محليًا
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000
